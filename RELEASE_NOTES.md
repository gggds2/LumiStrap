# LumiStrap 0.1.6

## 1. Novedades

- **Centro de actualizaciones:** consulta las novedades de una versión nueva y elige instalarla ahora o dejarla para después.
- **Temas Lumi:** incluye cinco paletas listas para usar y permite personalizar, importar y exportar temas `.lumitheme`.
- **Asistente inteligente de gráficos:** detecta el procesador, la memoria y el adaptador gráfico; recomienda Rendimiento, Equilibrio o Calidad y muestra los ajustes antes de aplicarlos.

## 2. Cambios

- **Copia antes de actualizar:** LumiStrap guarda un perfil de la configuración actual antes de instalar una versión nueva.
- **Perfiles gráficos:** añade la opción Equilibrio junto a Rendimiento y Calidad.
- **Apariencia:** las paletas Lumi cambian los colores de acento y funcionan tanto con el tema claro como con el oscuro.
- **Asistente gráfico plegable:** puedes contraer el panel después de revisar la recomendación.

## 3. Errores solucionados

- Se corrigió el selector de tema global para aplicar los modos claro y oscuro al instante.
- Se corrigió la aplicación de las paletas Lumi y se evitó que cambien el modo global de la aplicación.
- Se eliminaron las entradas duplicadas «personalizado» de las paletas incluidas; las variantes anteriores se migran a la paleta correspondiente.
